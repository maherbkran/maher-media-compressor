MediaLite source / build instructions
====================================
Windows x64, Python 3.14.3. The ready-made app needs no Python and no network.
This source code uses no networking. Downloads below are for building only.

1. Create a virtual environment and install requirements.txt.
   python -m venv .venv
   .venv\Scripts\python.exe -m pip install -r requirements.txt

2. The bundled binaries are in ../_internal/tools in the portable release.
   Copy that directory here as tools/ before testing or building.
   Copy ../_internal/licenses here as licenses/ as well.
   Alternatively obtain unmodified Windows x64 builds from:
   FFmpeg 9.0.2 essentials: https://www.gyan.dev/ffmpeg/builds/
   https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip
   libjpeg-turbo 3.2.0 gcc-x64:
   https://github.com/libjpeg-turbo/libjpeg-turbo/releases/tag/3.2.0
   Tools required: ffmpeg.exe, ffprobe.exe, jpegtran.exe, libjpeg-62.dll.
   Preserve upstream license files and notices in licenses/.

3. Run the integration tests (actual media encoders; takes a few seconds):
   .venv\Scripts\python.exe -m unittest test_engine test_ui test_large -v

4. Run from source:
   .venv\Scripts\python.exe launcher.py
   You may pass paths as command-line arguments; drag/drop also works.

5. Build the portable distribution:
   .venv\Scripts\python.exe make_icon.py
   .venv\Scripts\python.exe -m PyInstaller MediaLite.spec --noconfirm
   Distribute the entire dist/MediaLite directory, not only the EXE.
   Add the Arabic readme, source files, and third-party notices alongside it.

Architecture:
- launcher.py: startup boundary and headless portable-build diagnostics.
- medialite.py: Qt widgets UI, batch worker, progress, cancellation, CSV reports.
- settings_panel.py: independent quality/size/dimension controls for images and video.
- engine.py: validated immutable settings, measured size ceilings, Pillow/PNG, FFmpeg.
- External executables are invoked with argument arrays, never via a shell.
- No network imports, analytics, account access, or application updater.
- FFmpeg protocols are limited to local file/pipe input.
- Default: Instagram MP4 export, quality-based H.264 with two-pass ABR when the size cap binds,
  customizable per-media quality, size ceiling and dimensions, AAC, 30fps, orientation and HDR-to-SDR.
- ExportSettings: image quality is JPEG quality; video quality 1..100 maps to CRF 36..16.
  The requested quality is an upper preference. Byte ceilings take priority and may lower quality/resolution.
  A zero byte-size setting means unlimited. Transparent PNG meets its cap by resizing.
- The UI follows each input's parent directory by default. BatchWorker output=None
  routes each result beside its own source; a Path is an explicit shared destination.
- MediaLite.spec isolates DLL discovery from unrelated PATH entries during builds.

Portable-build smoke test (does not open a desktop window):
   dist\MediaLite\MediaLite.exe --self-test C:\path\to\empty-test-folder
Creates synthetic media and report.json, then exits with status 0 on success.

MediaLite 1.3.0: defaults are unlimited output size (0); export always writes JPEG/MP4.
branding.py owns app attribution and the user-authorized WhatsApp contact.
pillow-heif 1.8.1 supplies HEIC/HEIF support; FFmpeg decodes additional still formats.
Input video size and probe/encode time are not artificially capped. Resource limits still apply.
Legacy lossless engine functions remain for compatibility; the application UI always exports JPEG/MP4.
